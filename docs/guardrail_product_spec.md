# Guardrail Product Spec

Guardrail = Deterministic execution control for CLI, CI, and AI agents.

Core Features: - Command Contract Enforcement - Workflow Contracts -
Drift Detection - Scope Vector Engine - Autonomous Negotiation Loop -
Risk + Trust Classification - Audit Log - Time/Rate Policies - Resource
Controls

v2 Features: - Learning Mode - Agent Strict Mode - Explainability
Engine - Approval Acceleration
