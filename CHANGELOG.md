## 1.0.0 - 2026-08-20

### Added

- Contract-bound execution for direct commands, workflows, typed templates,
  versioned recipes, tool adapters, resident agent lanes, and delegated MCP
  operations.
- Reusable approvals that fail closed when the requested execution shape
  changes.
- Local manifests, structured logs, and hash-linked audit records that keep
  execution decisions inspectable without a hosted control plane.
- Public architecture, use-case, limitation, security, and contribution
  documentation.
- A strict npm publication allowlist and CI coverage for supported Node.js
  release lines.
